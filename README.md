# MECCA MOVE FULL MVP

지금까지 논의한 기능을 하나로 합친 통합본입니다.

## 포함 기능
- 실제 도로명주소 검색 (Daum 우편번호 서비스)
- 건물명/도로명/지번/우편번호 저장
- 검증된 도면만 사용한다는 정책
- 실제 도면 이미지/PDF 업로드
- 현재 집 사진 촬영/업로드
- TensorFlow.js COCO-SSD 기반 주요 가구 자동 인식
- 가구별 방/가로/세로 수정
- A/B/C 배치안
- 실제 도면 위 가구 오버레이 및 드래그
- 가져가기/교체검토/처분검토 판단
- 가구/조명/정리수납/입주서비스 연계 자리
- 이사업체용 방별 작업지시서
- 박스번호/도착방/내용 관리
- 작업지시서 TXT 저장
- 프로젝트 JSON 백업
- LocalStorage 자동 저장
- PWA manifest

## 실제 상용화 시 반드시 붙여야 하는 서버/데이터
1. 주소 기반 건물 식별 API
2. 실제 세대 평면도 데이터 공급 API/라이선스
3. 평면도 벡터화/방 경계 인식 AI
4. 상품 제휴 API
5. 사용자 계정/DB/결제/B2B 업체관리
6. 개인정보 및 위치정보 관련 동의/보안

## 중요한 정책
확인되지 않은 주소에 임의 59A/84A 도면을 생성하지 않습니다.
실제 도면 데이터가 없으면 사용자 업로드로 처리합니다.
